# Operations system

A deliberately simple, zero-cost setup the whole student team can run.

| Need | Tool | Cost |
| --- | --- | --- |
| Tasks, deadlines, partners, donations, events, projects | **CFK Operations Tracker** (Google Sheets) | $0 |
| Email triage | Gmail labels `CFK/…` (Corporate Sponsorships, Product Donations, Hospital Partnerships, Volunteer & Community, Fundraising & Events, Administrative, **Needs Reply**) | $0 |
| Donations, events, ticketing | Zeffy | $0 (no fees) |
| Design | Canva folder "CFK Brand System 2026" + templates in `brand/social/` | $0 with Canva for Nonprofits |
| Website updates | This repository (edit Markdown/config, push, auto-deploy) | $0 |

The tracker workbook is kept **outside** this repository because it contains partner contact details. Jacob has the file (`CFK-Operations-Tracker.xlsx`); import it into Google Sheets and share it with each director as Editor.

## Tracker tabs

- **Start Here**: how to use it, legend, roles, privacy rules.
- **Dashboard**: live counts (open/overdue tasks, tasks per owner, partner pipeline, donations, thank-yous outstanding).
- **Tasks**: one owner and one due date per task; overdue rows turn red.
- **Partners**: every company, hospital, grant or group: ask, status, last contact, next step.
- **Donations**: log every gift on arrival; track receipts and thank-yous.
- **Events** and **Projects**: dates, owners, status.

## Weekly rhythm (about 30 minutes total)

1. **Sunday:** each director updates their own rows (10 min).
2. **Monday standup (15 min):** Dashboard → overdue tasks → Gmail `CFK/Needs Reply` → this week's events.
3. **Friday:** send thank-yous for the week's gifts; tick the boxes in Donations.

## Privacy rules

- No patient names, diagnoses, room numbers or photos in the tracker, Canva, or the website.
- Product photos are fine; photos of children only with written parent/guardian permission (see [CONTENT-GUIDE.md](CONTENT-GUIDE.md)).
- Donor names are published only with the donor's permission.
